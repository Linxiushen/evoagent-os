# Launch Kit

## One-line pitch

The local-first control plane for agents that improve under evidence, approval and rollback discipline.

## Release post

EvoAgent Runtime v0.1 is available: persistent sessions, typed HTTP/WebSocket Gateway, tool risk policy, human approval and resume, memory, scheduling, audit events, and evaluation-gated prompt evolution. It runs fully offline for demos and supports OpenAI-compatible endpoints for real work.

## Demo script

1. Run `evoagent-runtime demo --state-dir .demo`.
2. Start the console and show the stable event ledger.
3. Submit `write: release.txt=ship after CI`; show the paused run.
4. Approve it and show the same run completing.
5. Add negative feedback, evaluate a candidate, and promote version 2.
