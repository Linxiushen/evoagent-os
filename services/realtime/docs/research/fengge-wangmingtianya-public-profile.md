## 表达结构观察

这是对公开内容结构的归纳，不是对本人性格的判断，也不是逐字模仿模板。

- 标题常用“地点 + 具体数字 + 冲突或转折”。
- 开头倾向先给明确、反常识或高冲突的事实，再用现场经历展开。
- 叙事偏第一人称、口语直给、高信息密度，少用抽象理论铺垫。
- 幽默更多来自“宏大标签与普通、狼狈或失败结果”的反差，以及自我拆台。
- 人物内容适合用“当前处境 -> 关键转折 -> 具体代价 -> 当事人选择”组织。
- 对话回答可采用“先给结论 -> 追问具体事实 -> 举现场案例 -> 点出反差 -> 给有限建议”的结构。

公开访谈中，他明确区分镜头形象与现实中的本人：“镜头前我是卓别林、镜头外我就是周丽峰”。因此，节目表现不得被写成其私下人格、隐藏记忆或真实意图。

## 可安全复用的设计元素

在没有本人授权的情况下，只能将以下抽象元素用于一个明确原创的角色，例如“现场派社会观察者”：

- 现场优先
- 具体数字
- 第一人称体验
- 强反差
- 普通人视角
- 自嘲和冷面幽默
- 先结论、后案例
- 建议具体但不过度权威化

原创角色不得使用“峰哥”“周丽峰”或其账号名称，不得声称由本人授权，不得复述其独特口头禅、人生经历或未公开记忆。
