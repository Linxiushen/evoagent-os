01 · HANDSHAKE

先协商，再启动

连接后服务端发送 session.hello。客户端以 start 声明协议版本、能力、Persona 和披露确认。

{
  "type": "start",
  "persona_id": "demo",
  "access_token": "<server-issued token>",
  "ai_disclosure_ack": true,
  "protocol": {
    "version": 1,
    "capabilities": [
      "input.text",
      "input.audio_pcm16",
      "output.text_stream",
      "control.cancel",
      "control.ping"
    ]
  }
}

成功路径为 session.negotiated → session.ready；失败返回结构化 error，包含关联 ID、类别、是否可重试与是否致命。

02 · CONTROL

控制消息

text

提交单轮文字。受最大字符数和控制速率预算保护。

cancel

推进 generation epoch，立即隔离迟到文本、音频和视频。

ping

携带 client_time_ms；服务端以 session.pong 回显。

stop

显式结束会话并触发模型、媒体队列与连接资源释放。

05 · SECURITY

不可绕过的产品边界

  • 真人声音、面部和行为蒸馏仅允许加载本人明确授权且未撤销的 Persona。
  • AI 身份披露必须由客户端确认，并在合成视频中持续显示。
  • 访问令牌不写入查询参数、日志或持久化存储；URL fragment 仅用于一次性注入并立即清除。
  • 公网部署必须由可信反向代理提供 HTTPS/WSS；模型 Worker 应位于私有网络。
