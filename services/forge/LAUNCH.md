# Launch Kit

**Pitch:** Sign, scan, test and evolve agent skills with evidence instead of trust-by-README.

**Release post:** EvoAgent Forge v0.1 turns `SKILL.md` projects into reproducible `.evoskill` artifacts with capability transparency, security gates, Ed25519 signatures, immutable content-addressed releases, registry search and regression-driven evolution.

**Demo:** scaffold a skill, intentionally add `httpx` without declaring `network.http`, show the blocked build, fix the capability, package twice with identical digest, sign, publish and inspect it in the registry console.

**Topics:** `agent-skills`, `ai-agents`, `software-supply-chain`, `ed25519`, `reproducible-builds`, `skill-registry`, `self-evolving-agents`
