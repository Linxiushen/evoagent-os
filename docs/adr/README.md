# Architecture Decision Records

ADRs record decisions that affect multiple components or long-term compatibility.

| ADR | Decision | Status |
| --- | --- | --- |
| [0001](0001-independent-services-in-one-monorepo.md) | Keep independently runnable services in one monorepo | Accepted |
| [0002](0002-sqlite-for-the-reference-runtime.md) | Use SQLite for the single-host reference runtime | Accepted |
| [0003](0003-explicit-governance-before-autonomy.md) | Make approvals, leases, budgets and signed Skills explicit | Accepted |

New ADRs should include context, decision, consequences and alternatives. Supersede an accepted ADR with a new record instead of silently rewriting the original decision.
